# Mission

Kaivor is a Personal Knowledge Operating System (PKOS).

It is not simply an AI assistant.

The AI is one component of a wider platform whose purpose is to organise, retrieve, manage and expand personal knowledge while intelligently using AI services only when necessary.

---

# Core Principles

1. User owns all knowledge.

2. AI providers are interchangeable.

3. Knowledge before AI.

4. Architecture before features.

5. Automation where valuable.

6. Mobile-first development.

7. Privacy by default.

8. Every feature must have a clear purpose.

---

# Engineering Principles

Every change must:

- Improve architecture
- Reduce technical debt
- Remain backwards compatible where practical
- Be documented
- Be testable
