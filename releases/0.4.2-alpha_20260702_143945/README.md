# Kaivor

Kaivor is a personal intelligence platform built in Python.

It aggregates news from multiple RSS feeds, stores articles in a local database, and provides searchable intelligence across multiple categories.

## Current Features

- AI Intelligence
- UK News
- World News
- Technology News
- Investment Research
- Football News
- Android News
- Music News
- Article Database
- Search Engine
- Morning Dashboard

## Project Goals

Kaivor aims to become an AI-powered personal intelligence platform with:

- AI-generated news summaries
- Daily Morning Briefing
- Gmail integration
- Calendar integration
- Investment tracking
- Android companion app
- Loveable web interface
