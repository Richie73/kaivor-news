Kaivor FP094 — Clickable links in chat
====================================

WHAT CHANGED
------------
renderAiMarkdown had no link support, so a web address the model
gave in a chat reply (or an AI brief) showed as plain text you
could not tap.

Now both forms render as links opening in a new tab:
- Markdown links: [BBC report](https://www.bbc.co.uk/news)
- Bare URLs: https://example.com/foo

Only http(s) links are made tappable, so a javascript: URL stays
plain text. Code spans are never linked. Trailing sentence
punctuation (a full stop after a bare URL) stays outside the
link. Bold, italic and code formatting still work alongside.
